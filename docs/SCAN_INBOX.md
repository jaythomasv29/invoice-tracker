# Editable invoices and nonblocking Smart Sift scans

A pencil beside the vendor name opens a labelled editor on both review and saved invoices. Users can correct the vendor/store, invoice/receipt number, purchase date, subtotal, tax and printed total. Edits commit atomically through a workspace-scoped RPC. Vendor corrections reassign only the selected invoice to a matching scoped vendor (or create one); shared Unknown vendor records are not renamed. The extracted review also supports description, quantity and price corrections before final save. Printed total edits do not rewrite line items.

Capture remains locked only while preparing and uploading photos. Once uploaded, a root-level provider owns extraction and the app returns to the invoice/receipt library. Users can navigate other tabs or start another scan. Home and the library expose the scan inbox; the library tab badge shows unfinished scans. Completion changes the inbox to Ready to review and shows an in-app toast; it never forcibly navigates away from the user's current task. Duplicate checks, plan limits, provider consent and final explicit review/save remain enforced.

The inbox reads uploaded pending and scanned records from the server, including after relaunch. Progress polls while the app is active and refreshes when it resumes. Lost responses first recover committed invoices. Interrupted jobs older than ten minutes can be safely released for explicit retry; active jobs cannot restart or be discarded. Failed uploads offer a new scan, while fully uploaded drafts reuse their photos. No automatic retry spends additional model calls. All UI updates are guarded by session/workspace scope.

This supports continuing work inside Sift. It does not promise iOS background execution, push notifications, or guaranteed completion after force-quitting; returning to the inbox recovers the server result or offers retry. No native dependencies were added.

Verification: TypeScript, lint, 51 Node tests; full-schema PostgreSQL tests for atomic edits, scanned line edits, cross-workspace restrictions, shared-vendor preservation, inbox filtering, interrupted-job recovery and active-job protection; 14 hosted checks using disposable Clerk identities and synthetic records (cleaned up). Browser preview verifies the pencil/form, corrected vendor/date, and processing/ready/duplicate/retry states at phone width. Native keyboard, VoiceOver and physical-phone behavior remain phone QA items.
